# セキュリティおよび非機能要件

## 1. セキュリティ要件

- Firebase Auth による認証とセッション管理
- TLS による全通信の暗号化
- E2EE によるメッセージ暗号化
- テナントマスターキーとユーザー端末ローカル鍵の二重鍵設計
- マスターキーのみではメッセージ本文を復号できない鍵管理
- ストレージの暗号化とアクセス制御
- OAuth2.0 / OIDC 準拠
- XSS / CSRF / インジェクション対策
- 端末移行をサポートする復活の呪文（リカバリフレーズ）

## 2. 信頼性要件

- サーキットブレーカーによる障害の局所化
- 自動スケーリング対応
- 監視とログ（Cloud Logging / Monitoring）
- テナントごとのメタデータ監査ログの保全
- 監査情報とコンテンツ暗号化を分離した運用

## 3. パフォーマンス要件

- 低レイテンシ通信の実現
- オフラインファースト設計
- キャッシュ戦略と同期戦略
- プッシュ通知遅延の最小化

## 4. 運用要件

- ログ保管・解析体制の確立
- アラート設定と障害通知
- アップデート時の後方互換性

## 5. テスト要件

- 単体テスト、統合テスト、E2E テスト
- セキュリティテスト
- パフォーマンステスト
- 回帰テスト
